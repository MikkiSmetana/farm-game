# 🌾 Веселая Ферма - Браузерная Игра

Полнофункциональная браузерная игра-ферма с монетизацией на косметические предметы для детей.

## 🎮 Игровой процесс

### Вкладка "Ферма" 🌾
- Выращивайте растения (пшеница, кукуруза, помидоры, морковь, яблоки, тыквы)
- Каждое растение имеет время роста (от 8 до 25 секунд)
- Собирайте урожай и получайте монеты
- 9 ячеек для посадки одновременно

### Вкладка "Животные" 🐄
- Покупайте животных (курицы, коровы, свиньи, овцы, утки, лошади)
- Каждое животное производит монеты каждые N секунд
- Собирайте монеты от животных
- Применяйте косметические скины

### Вкладка "Магазин" 🛍️
- Купите кристаллы за реальные деньги
- Пакеты от $4.99 до $49.99
- Получайте от 50 до 800 кристаллов
- Мини-игра платежей

### Вкладка "Декорации" ✨
- Украшайте вашу ферму декоративными предметами
- Деревья, цветы, фонтаны, мосты и многое другое
- Все покупаются за кристаллы

## 💰 Монетизация

### Косметические предметы (этичная монетизация)
- Скины для животных - видимые персонализации
- Декорации для фермы - косметический элемент
- **Без pay-to-win** - ничего не дает преимуществ
- **Без лутбоксов** - только честные покупки

### Система валют
- **💰 Монеты** - зарабатываются в игре за урожай и животных
- **💎 Кристаллы** - покупаются за деньги, используются для косметики

## 🚀 Как запустить

1. Откройте `index.html` в браузере
2. Игра полностью работает локально в браузере
3. Прогресс сохраняется в `localStorage`

### Локальный сервер (рекомендуется)
```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server

# Или используйте Live Server в VSCode
```

Затем откройте: `http://localhost:8000`

## 🔧 Кастомизация

### Добавить новое растение
В `data.js`, в массив `GAME_DATA.crops`:
```javascript
{ id: 'banana', name: 'Банан', emoji: '🍌', growTime: 18000, coins: 90, water: 3 }
```

### Добавить новое животное
В `data.js`, в массив `GAME_DATA.animals`:
```javascript
{ id: 'goat', name: 'Коза', emoji: '🐐', cost: 180, income: 40, collectTime: 13000 }
```

### Добавить товар в магазин
В `data.js`, в массив `GAME_DATA.shopItems`:
```javascript
{ id: 'gem-pack-5', name: 'Ультра пакет', emoji: '💎', price: 99.99, gems: 2000, category: 'gems' }
```

## 📊 Статистика игры

Средние значения для балансировки:
- Пшеница: 10сек роста = 50 монет (5 монет/сек)
- Курица: 100 монет = 20/8сек = 2.5 монеты/сек доход
- Корова: 250 монет = 50/15сек = 3.3 монеты/сек доход
